# English style guide and glossary — "Một ngày làm nghề"

The game is a cozy Vietnamese career simulator. English should read naturally and stay warm and casual. Address the player as "you", and keep the length close to the Vietnamese because space in buttons and labels is tight.

## Hard rules
- Keep every `$1`, `$2`… placeholder exactly as it is: same numbers, each used once. Word order may change around them.
- Keep emoji, numbers, units (kg, g, °C, %, ml, cm), codes (lot-3, INV-102, TK 331, PLU 4011), account numbers and anything inside `{…}` unchanged.
- Keep leading and trailing punctuation and symbols (…, :, ·, →, “ ”, —).
- If the Vietnamese is ALL CAPS, write the English in ALL CAPS.
- If a string is a fragment (starts lowercase, or clearly continues another string), translate it as a fragment.
- Game data is fictional; don't add or remove facts.

## Names and forms of address
Keep Vietnamese personal names with their diacritics (Lan, Tùng, Hạnh, Bảy). Translate the title in front of a name:

| Vietnamese | English |
|---|---|
| Cô X | Ms. X (a teacher or a middle-aged woman; for the grocer "Cô Ba", use "Auntie Ba") |
| Chú X | Uncle X |
| Bà X | Grandma X |
| Ông X | Mr. X (an elderly man, or a formal context) |
| Anh X / Chị X | X (with no title) |
| Em X / Bé X | little X (for a child: "little Na") |
| thầy X | Mr. X (a teacher) |

When a pronoun is ambiguous, use they/them.

## Culture
- Tết stays **Tết** (write "Lunar New Year" only when it needs explaining).
- Trung thu → **Mid-Autumn Festival**.
- 20/11 → **Teachers' Day (Nov 20)**. 20/10 → **Vietnamese Women's Day (Oct 20)**. 8/3 → **Women's Day (Mar 8)**.
- Keep dish names: **bánh chưng, bánh mì, phở, bún bò, cà phê sữa đá**. Add a short gloss only when the meaning matters: "bánh chưng (sticky rice cake)".
- Hội khỏe Phù Đổng → **Phù Đổng sports day**.
